## 🚀 Featured Projects

### [🤖 R1-Omni — Explainable Omni-Modal Emotion Recognition](https://github.com/ZamoRzgar/R1-Omni)

Multimodal (video/audio/text) → fused reasoning → emotion classification with explainability. Built with PyTorch; uses efficient training loops and modular encoders.

[![R1-Omni](https://img.shields.io/badge/View_Repository-R1--Omni-blue?style=for-the-badge&logo=github)](https://github.com/ZamoRzgar/R1-Omni)

---

### [🕸️ GNN Fraud Detection](https://github.com/ZamoRzgar/gnn-fraud-detection)

Imbalance-aware Graph Neural Network for fraud detection, combining camouflage-resistant neighbor selection (CARE-GNN) with balanced sampling (PC-GNN). Evaluated on YelpChi and Amazon benchmarks with PyTorch + PyG.

[![gnn-fraud-detection](https://img.shields.io/badge/View_Repository-GNN--Fraud--Detection-blue?style=for-the-badge&logo=github)](https://github.com/ZamoRzgar/gnn-fraud-detection)

---

### [🔐 Image Security Verification](https://github.com/ZamoRzgar/image-security-verification)

Web app for authenticating images with RSA digital signatures and SHA-256 hashing. Client-side key generation (private keys never leave the device), built with Next.js, TypeScript, and Supabase.

[![image-security-verification](https://img.shields.io/badge/View_Repository-Image--Security--Verification-blue?style=for-the-badge&logo=github)](https://github.com/ZamoRzgar/image-security-verification)

---

### [🧠 Multi-Agent RCA System](https://github.com/ZamoRzgar/Multi-agent-RCA-project)

Multi-agent, knowledge-graph-guided root cause analysis for system logs. Specialized LLM agents debate competing hypotheses, grounded by a Neo4j incident knowledge graph — runs fully locally via Ollama.

[![Multi-agent-RCA-project](https://img.shields.io/badge/View_Repository-Multi--Agent--RCA-blue?style=for-the-badge&logo=github)](https://github.com/ZamoRzgar/Multi-agent-RCA-project)
